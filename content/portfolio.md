# پورتفولیوی [علی شمس الدین]

## درباره من
برنامه‌نویس فرانت‌اند با تمرکز بر React و Next.js. دارای [تعداد] پروژه عملی کامل شامل فروشگاه کتاب، وبلاگ، سایت فیلم و اپلیکیشن هواشناسی. تمرکز بر کد تمیز، بهینه‌سازی عملکرد و تجربه کاربری روان. علاقه‌مند به یادگیری تکنولوژی‌های جدید مثل GraphQL و هوش مصنوعی.

## پروژه‌ها

### 1. سامانه وبلاگ با مدیریت محتوا
**تکنولوژی:** Next.js, Server Actions, React Hook Form, NextAuth

**توضیحات:** وبلاگ کامل با پنل مدیریت محتوا. ایجاد، ویرایش و حذف پست‌ها با Server Actions بدون نیاز به API Route. سیستم نقش‌دهی (بازدیدکننده، نویسنده، ادمین) با NextAuth.

**نکات فنی:**
- استفاده از useOptimistic برای تجربه کاربری روان
- فرم چندمرحله‌ای ایجاد پست با آپلود تصویر
- ویرایشگر متن با پیش‌نمایش زنده
- بهینه‌سازی سئو با Metadata API

**لینک:** [دمو](https://my-blog-blond-eight-92.vercel.app/) | [گیت‌هاب](https://github.com/AliShams2002/My-Blog)

### 2. سایت فیلم و سریال
**تکنولوژی:** React, TMDB API, React Router, Zustand

**توضیحات:** سایت مشاهده و جستجوی فیلم و سریال با اتصال به TMDB API. جستجوی لحظه‌ای با Debouncing، اینفینیتی اسکرول، و قابلیت ذخیره لیست تماشا.

**نکات فنی:**
- بهینه‌سازی جستجو با Debouncing و کاهش ۶۰٪ درخواست‌های تکراری
- اینفینیتی اسکرول با Intersection Observer
- Lazy Loading تصاویر و کد اسپلیتینگ
- مدیریت وضعیت لیست تماشا با Zustand

**لینک:** [دمو](https://movie-app-two-teal-97.vercel.app/) | [گیت‌هاب](https://github.com/AliShams2002/Movie-app)

### 3. دستیار هوشمند پورتفولیو (AI)
**تکنولوژی:** Next.js, Vercel AI SDK, OpenAI

**توضیحات:** چت‌بات هوشمند که به سوالات بازدیدکنندگان درباره پروژه‌ها و مهارت‌ها پاسخ می‌دهد. استفاده از تکنیک Context Stuffing برای ارسال محتوای پورتفولیو به مدل زبانی.

**نکات فنی:**
- استریم پاسخ‌ها به صورت real-time با Vercel AI SDK
- امن‌سازی کلید API با API Routes
- طراحی system prompt برای جلوگیری از توهم (Hallucination)
